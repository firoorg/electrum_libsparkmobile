# Third-party components

The built shared library statically contains the components below. Their
license terms apply to any distribution of that binary.

| Component | Use | License |
| --- | --- | --- |
| [sparkmobile](https://github.com/firoorg/sparkmobile) | Spark protocol: keys, coins, mint and spend construction | MIT |
| secp256k1 (vendored inside sparkmobile) | elliptic-curve arithmetic | MIT |
| Bitcoin Core / Firo Core primitives (`src/transaction.*`, and `bitcoin/` inside sparkmobile) | transaction and serialization primitives | MIT |
| [OpenSSL 1.1.1w](https://www.openssl.org/) via [janbar/openssl-cmake](https://github.com/janbar/openssl-cmake) | SHA-512, ChaCha20-Poly1305, `RAND_bytes`, memory cleansing | OpenSSL License and SSLeay License (dual) |
| [Boost 1.71.0](https://www.boost.org/) | headers and a few compiled libraries | Boost Software License 1.0 |
| [Orphis/boost-cmake](https://github.com/Orphis/boost-cmake) (vendored, modified) | CMake integration for Boost | New BSD License |

GMP is **not** linked. The build previously picked it up when it happened to be
installed on the build machine, which made binaries differ between machines and
introduced an LGPL dependency; secp256k1 now always uses its builtin field and
scalar inversion.

The full text of every licence that applies to the distributed binary is
included below, so it travels with the source and with any packaged library.
Referring to files that exist only inside a temporary build checkout is not
enough, because those checkouts are not shipped.
